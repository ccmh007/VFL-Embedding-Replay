## 复现命令

```bash
cd code
pip install -r requirements.txt

python train.py --dataset CIFAR10 --epochs 100 --batch-size 128 --lr 0.1 \
    --milestones 50 75 --threads 24 --out-dir runs/cifar10

# 比例实验（以 A 方 10% 为例；其余比例改 --feature-ratio 与 --out-dir）
python train.py --dataset CIFAR10 --epochs 60 --batch-size 128 --lr 0.1 \
    --milestones 30 45 --feature-ratio 0.1 --threads 24 --out-dir runs/cifar10_ratio_10

# 拐点实验（以 32% 为例；只训练 10/11/12/13/14/15 列对应的 6 个模型）
python train.py --dataset CIFAR10 --epochs 60 --batch-size 128 --lr 0.1 \
    --milestones 30 45 --feature-ratio 0.32 --threads 8 --out-dir runs/cifar10_ratio_32

python predict.py --checkpoint runs/cifar10/best.pth --data-dir data
```

攻击实验由独立脚本完成，不混入主程序；脚本与中间结果在 `_work/`，不随课程提交。
比例实验的每个模型都用同一套配置评测：高置信度选择、k=50、目标类 automobile、源类 airplane，
总体 ASR 在除目标类外的 9000 个测试样本上统计。五个比例的 ASR 依次为
0.53%、0.79%、98.79%、100.00%、100.00%，对应主任务 top-1 为
91.00%、89.42%、89.09%、89.72%、90.96%。

细粒度实验在 32%~48% 内取 9 个名义比例，按整列掩码实际只有 10/11/12/13/14/15 六种列数，
对应 ASR 为 3.04%、5.71%、30.83%、49.08%、76.60%、91.58%；按“首次超过 50%”定义，
拐点在 42%~44%（13→14 列），12 列时 ASR 已从 3%~6% 抬升到 30.83%。
